## 发布网页

仓库根目录的 `index.html` 为完整静态网页，`.nojekyll` 用于直接发布静态文件。

在仓库 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**，选择 `master` 分支和 `/(root)`，保存。

部署成功后，默认网页地址为：

https://1070470144.github.io/shalieluosiyinsi/

实际部署状态及地址以 GitHub Pages 设置页面为准。填写平台的隐私政策网址时，请使用已经可以公开访问的 HTTPS 网页地址，不要使用 GitHub 仓库代码页地址。

本仓库仅提供政策网页。游戏内的政策入口和其他客户端接入，待 HTTPS 页面就绪后另行处理。
